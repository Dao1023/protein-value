## 算法

```
元/克蛋白质 = 每斤价格 ÷ (蛋白含量 g/100g × 5 × 食部)
```

一斤 500 克，所以每斤含蛋白 `蛋白含量 × 5` 克；带壳、带骨、带荚的按可食部折算（鸡蛋 88%、虾 67%、整鱼 58%、毛豆 53%）。

⚠️ 常见错误写法是 `单价 × 蛋白含量 ÷ 100`，量纲不成立，方向也相反：它奖励「又贵又高蛋白」的食物。

## 品种与密度

同名食物拆到品种与部位：南豆腐 6.2、北豆腐 12.2、豆腐干 16.2、千张 24.5，相差四倍，把「豆腐」当成一个数就会算错。每行带 `common / less / rare` 标签，页面顶部可按密度筛选（只看常见 / 全部品种）。

## 数据

- **蛋白质含量**：《中国食物成分表》第 6 版 / 中国疾控中心营养与健康所 [食物营养成分查询平台](https://nlc.chinanutri.cn/fq/)；未收录项用 USDA FoodData Central 补。取可食部；谷物豆制品取干重，馒头取熟重。
- **价格**：统一**零售**口径。生鲜取北京菜市场/农贸当日价，包装食品取商超与电商日常价。批发价不进表——同日大白菜批发 0.31、农贸 0.76 元/斤，拿批发价当买菜价会系统性低估 30–150%。
- 全部数字见 [`data.csv`](data.csv)，由 `build_page.py` 从 `data.json` 生成。

## 局限

1. 价格随城市、季节、规格波动极大（三文鱼冰鲜/冻品差 2 倍，虾按头数差 1.5 倍），渠道误差约 10–20%。
2. 只算粗蛋白，未做氨基酸评分与消化率修正。按 DIAAS（鸡蛋≈1.1、小麦≈0.5）折算，鸡蛋其实比干挂面便宜一半。
3. 未计入烹饪损耗与时间成本。
