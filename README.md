# 蛋白质性价比 · 22 种常见食物

把「每斤多少钱」和「每斤含多少克蛋白质」放在同一把尺子上量，算出**每克蛋白质的真实价格**。

| 22 | 三文鱼（冰鲜柳） | **1.471** |

黄豆与三文鱼相差 **40 倍**。**豆制品包揽前五**；鸡蛋（0.103）与干挂面（0.119）几乎持平——因为鸡蛋 74% 是水，而挂面只有 12%。牛奶 0.333、虾 0.522、牛里脊 0.523 排在后面：它们卖的从来不是蛋白质。

## 算法

```
元/克蛋白质 = 每斤价格 ÷ (蛋白含量 g/100g × 5 × 食部)
```

一斤 500 克，所以每斤含蛋白 `C × 5` 克；带壳、带骨、带荚的按可食部折算（鸡蛋 88%、虾 67%、草鱼/鲈鱼 58%、毛豆 53%）。

换算例：黄豆 35g/100g、6.5 元/斤 → `6.5 ÷ (35×5) = 0.037 元`。

⚠️ 常见错误写法是 `单价 × 蛋白含量 ÷ 100`，量纲不成立，而且方向相反：它奖励「又贵又高蛋白」的食物，会把米饭排到第一、黄豆排到第十一。

## 数据

- **蛋白质含量**：《中国食物成分表》第 6 版 / 中国疾控中心营养与健康所 [食物营养成分查询平台](https://nlc.chinanutri.cn/fq/)；三文鱼等未收录项用 USDA FoodData Central 补。取可食部；谷物豆制品取干重，馒头取熟重。
- **价格**：统一**零售**口径。生鲜取北京菜市场/农贸当日价，包装食品取商超与电商日常价（2026-11-16）。批发价不进表——同日大白菜批发 0.31、农贸 0.76 元/斤，拿批发价当买菜价会系统性低估 30–150%。
- 全部数字见 [`data.csv`](data.csv)；馒头、冻虾、真希腊酸奶三项暂无终端零售实证，标「待核」。

## 局限

1. 价格随城市、季节、规格波动极大（三文鱼冰鲜/冷冻差 2 倍，虾按头数差 1.5 倍）。本页取一线城市零售价并标注规格，误差约 10–20%。
2. 只算粗蛋白，未做氨基酸评分与消化率修正。按 DIAAS（鸡蛋≈1.1、小麦≈0.5）折算，鸡蛋其实比干挂面便宜一半。
3. 未计入烹饪损耗与时间成本。
