# 蛋白质性价比 · 21 种常见食物

把「每斤多少钱」和「每斤含多少克蛋白质」放在同一把尺子上量，算出**每克蛋白质的真实价格**。

🔗 在线页面：<https://dao1023.github.io/protein-value/>

## 结论

| # | 食物 | 元/克蛋白 |
|---|---|---|
| 1 | 黄豆（干） | **0.029** |
| 2 | 花生仁 | 0.065 |
| 3 | 老豆腐 | 0.066 |
| 4 | 豆腐干 | 0.080 |
| 5 | 腐竹（干） | 0.081 |
| … | … | … |
| 21 | 希腊酸奶 | **1.778** |

黄豆与希腊酸奶相差 61 倍；与三文鱼（1.373）相差 47 倍。**豆制品包揽前五**，鸡蛋与干挂面几乎持平（0.103 vs 0.089）。

## 算法

```
元/克蛋白质 = 每斤价格 ÷ (蛋白含量 g/100g × 5 × 食部)
```

一斤 500 克，所以每斤含蛋白 `C × 5` 克；带壳、带骨、带荚的按可食部折算（鸡蛋 88%、虾 67%、草鱼/鲈鱼 58%、毛豆 53%）。

⚠️ 常见错误写法是 `单价 × 蛋白含量 ÷ 100`，量纲不成立，而且方向相反：它奖励「又贵又高蛋白」的食物，会把米饭排到第一、黄豆排到第十一。

## 数据

- **蛋白质含量**：《中国食物成分表》第 6 版 / 中国疾控中心营养与健康所 [食物营养成分查询平台](https://nlc.chinanutri.cn/fq/)；三文鱼等未收录项用 USDA FoodData Central 补。取可食部；谷物豆制品取干重，馒头取熟重。
- **价格**：北京新发地农产品批发市场 2026-11-16 行情为锚点，按品类加价 1.3–1.8 倍推零售；牛奶、酸奶、挂面、馒头、黄豆用商超与电商折算。单位：元/斤。
- 全部数字见 [`data.csv`](data.csv)。

## 局限

1. 价格随城市、季节、规格波动极大（三文鱼冰鲜/冷冻差 2 倍，虾按头数差 1.5 倍）。本页取一线城市商超常见价，并标注规格。
2. 只算粗蛋白，未做氨基酸评分与消化率修正。按 DIAAS（鸡蛋≈1.1、小麦≈0.5）折算，鸡蛋其实比干挂面便宜一半。
3. 未计入烹饪损耗与时间成本。
